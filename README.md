# Drop Cart Elite

Desenvolva um site completo de e-commerce para a DROP Skate Shop, uma loja especializada em produtos para skate, streetwear e lifestyle urbano.

O design deve ser moderno, premium, minimalista e extremamente intuitivo, proporcionando uma experiência de compra rápida e agradável em computadores, tablets e smartphones.

Identidade Visual

Utilize como referência a logomarca enviada.

A identidade visual deverá seguir exatamente o conceito da marca.

Paleta de cores

 Preto (#0B0B0B)

 Grafite (#1C1C1C)

 Branco (#FFFFFF)

 Laranja vibrante (#F57C00)

 Tons de cinza para elementos secundários

O laranja deve ser utilizado para destacar botões, promoções, preços, ícones ativos e chamadas para ação.

O restante do layout deve ser predominantemente escuro.

O site deve transmitir uma sensação de tecnologia, velocidade, exclusividade e cultura do skate.

Experiência do Usuário (UX)

Criar uma experiência premium inspirada nos maiores e-commerces do mercado, com navegação fluida, menus intuitivos, carregamento rápido e animações discretas. O visual deve transmitir a identidade da cultura do skate, utilizando as cores da marca (preto, grafite, branco e laranja) para criar uma atmosfera urbana e moderna.

Incluir microinterações elegantes em botões, cartões de produtos, menus e formulários, além de transições suaves entre páginas. O layout deve valorizar imagens de alta qualidade dos produtos e oferecer uma jornada de compra simples, desde a descoberta até a finalização do pedido.

Tecnologias

Utilize tecnologias modernas e escaláveis, priorizando:

 React + Next.js

 TypeScript

 Tailwind CSS

 Componentes reutilizáveis

 Design System consistente

 Banco de dados PostgreSQL

 Prisma ORM

 API REST ou GraphQL

 Autenticação segura com JWT e OAuth

 Preparação para hospedagem em Vercel ou Cloudflare

O código deve ser limpo, modular, documentado e de fácil manutenção, permitindo futuras integrações com ERPs, marketplaces (Mercado Livre, Shopee e Amazon), sistemas de pagamento e ferramentas de marketing. O resultado final deve ser um e-commerce de nível profissional, visualmente marcante e pronto para crescer junto com a DROP Skate Shop.
